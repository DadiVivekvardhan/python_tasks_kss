================================================
SWAGGER TODO OPERATIONS
================================================

CREATE TASK
POST /tasks

Example:
{
  "title": "Learn FastAPI",
  "description": "Understand APIs and FastAPI"
}


FETCH ALL TASKS
GET /tasks

No request body required.


UPDATE TASK STATUS
PUT /tasks/{task_id}

task_id:
1

Request body:
{
  "status": "in progress"
}

Available statuses:
- not yet started
- in progress
- completed


DELETE TASK
DELETE /tasks/{task_id}

task_id:
1
